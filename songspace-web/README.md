# 歌境 SongSpace

Vue 3、TypeScript、Three.js 与 GSAP 实现的音乐骑行和卡牌收藏游戏。本地版本可独立运行。

## 启动与验证

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 5173
npm run build
node --experimental-strip-types tests/economy.mjs
```

打开 http://127.0.0.1:5173/ 。经济系统测试使用隔离的内存存档，不影响浏览器玩家进度。

## 当前玩法

- 游戏页选择《挪威的森林》《大海》《江南》，三个初始地图直接开放。
- 第三人称圆润小人骑自行车，路段循环延伸、雾化地平线；海岸有动态海浪，水乡为青石板街、石桥、白墙黛瓦、垂柳和乌篷船。
- 自动骑行，A/D 或左右方向键换道，空格跳跃，S 减速，Esc 暂停。移动窗口提供换道和跳跃按钮。
- 吃金币、避障、三次碰撞结束。每 500 米进入下一关，速度逐渐提高。每米 1 分，每枚金币 50 分，结算每 40 分兑换 1 音符。
- 初始赠送 120 音符和一个五连包。每日签到 50 音符。
- 卡包商店、库存、金卡保底、拖动撕封或按钮撕包、GSAP 包装与翻卡动画。购买和开启分别扣音符、扣库存；卡牌在撕包时入库，关闭或刷新不会丢卡。
- 100 首真实 QQ 音乐热歌及封面。仓库未拥有封面灰显，支持分类、搜索、拥有筛选、详情和 QQ 音乐跳转。
- 金卡提供每局一次加速助力；重复卡每三个额外副本升一级，增加助力时长。载具卡提供配色及巡航速度，重复卡增加速度。彩色主题卡启用星空夜骑灯光。
- 矩形微缩世界，获得装饰卡后可摆放花簇、撤回与本机保存。
- 每日卡通意象猜歌，六次机会：首次猜中五连包，2–3 次三连包，4–6 次单抽包。当前题库三题按日期轮换；正确或次数耗尽后当天不能再次作答，奖励只发一次。
- 昵称、本机进度、装备与最近十次闯关记录保存。

## 规则与边界

歌曲卡功能分配与音符价格是当前可玩的初始规则，还不是对 100 首歌曲逐首完成的意象策划。当前装饰为花簇，道具为加速，载具为自行车；赛车、复活等不同道具、专属歌曲模型尚未实现。

三张初始地图始终可选。彩卡当前解锁夜骑灯光，尚不生成新地形；《光年之外》的太空地图与星球车仍为后续内容。

账号是本机昵称存档，没有服务器认证、跨设备同步、共享排行榜或反作弊。不要把本机记录页视为多人排行榜。后端基础工程尚未接入这些游戏交易。

榜单快照日期 2026-10-08，数据来源与完整名单见 public/catalog 和 docs/plans/2026-10-08-qqmusic-hot-100.md。

生产构建有 Three.js 包体超过 500 kB 的提示；低性能设备帧率和真实移动设备尚未验证。

## 已验证

生产构建及 TypeScript 检查通过；经济系统测试覆盖得分兑换、购买扣款、余额不足、卡包耗尽、五连保证、二十抽保底、每日领取幂等、载具/主题池和存档。

真实浏览器验证：399 米、19 金币、1349 分结算 33 音符；60 音符购买增加库存；拖动包装撕开，五张真实歌曲卡入库；连续翻卡归位；首次猜中获得五连包；道具装备后加速至约 68 km/h；三个世界可选择。
