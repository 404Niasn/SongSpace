# 歌境 SongSpace

Vue 3、TypeScript、Three.js 与 GSAP 实现的音乐探索和卡牌收藏游戏。本地版本可独立运行。

## 启动与验证

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 5173
npm run build
node --experimental-strip-types tests/economy.mjs
```

打开 http://127.0.0.1:5173/ 。经济系统测试使用隔离的内存存档，不影响浏览器玩家进度。

登录页位于 `/login`。上方输入 2-16 个字的名字作为账号 ID，点击注册；下方使用已有账号 ID 登录并跨设备恢复存档，ID 区分大小写。后端校验重名，新注册账号使用初始存档。点击大厅右上角昵称可查看、复制 ID 或退出登录。ID 相当于密码，请妥善保存。退出前会同步进度，再清除本机登录状态及缓存；同步失败时保留当前进度。重新登录可恢复服务端存档，旧会话 ID 继续兼容。登录与同步验证：`node --experimental-strip-types tests/login.mjs`。

## 当前玩法

- 游戏页选择《挪威的森林》《大海》《江南》，三个初始地图直接开放。
- 第三人称圆润小人骑自行车，路段循环延伸、雾化地平线；海岸有动态海浪，水乡为青石板街、石桥、白墙黛瓦、垂柳和乌篷船。
- 自动探索，A/D 或左右方向键换道，空格跳跃，S 减速，Esc 暂停。移动窗口提供换道和跳跃按钮。
- 吃金币、避障、三次碰撞结束。每 500 米进入下一关，速度逐渐提高。每米 1 分，每枚金币 50 分，结算每 40 分兑换 1 音符。
- 初始赠送 120 音符和一个五连包。每日签到 50 音符。
- 卡包商店、库存、金卡保底、拖动撕封或按钮撕包、GSAP 包装与翻卡动画。购买和开启分别扣音符、扣库存；卡牌在撕包时入库，关闭或刷新不会丢卡。
- 100 首真实 QQ 音乐热歌及封面。仓库未拥有封面灰显，支持分类、搜索、拥有筛选、详情和 QQ 音乐跳转。
- 金卡提供歌曲专属道具，赛前装备两个槽，局内点击或按 1/2 使用，每局各一次。重复卡每三个额外副本升一级，增加时长或保护。载具卡提供配色及巡航速度，重复卡增加速度。彩色主题卡启用星空夜间探索灯光。
- 矩形微缩世界支持花园、雪庭、青瓷灯、观景台及唱片亭等装饰；库存跨地图共用，撤回返还、本机保存，闯关前段能看到已摆放物件。
- 每日卡通意象猜歌，六次机会：首次猜中五连包，2–3 次三连包，4–6 次单抽包。当前题库三题按日期轮换；正确或次数耗尽后当天不能再次作答，奖励只发一次。
- 昵称、本机进度、装备与最近十次闯关记录保存。

## 规则与边界

歌曲卡功能分配与音符价格是当前可玩的初始规则，普通装饰尚未逐首完成专属意象策划，部分复用唱片亭。九种金卡道具包含护盾、吸币、自动复活、冲刺防撞、回血、冻结动态障碍、延迟双倍、回溯及友情助力，每张具有独立原创中文文案。

单件装饰值 20–50，仅当前世界已摆放物件计值；每 100 值提高积分 10%，最高 1.50 倍。积分加成后按每 40 分兑换一个音符，开局锁定倍率。回溯同步恢复生命、距离、金币与领取标记，避免重复刷分。

三张初始地图始终可选。彩卡当前解锁夜间探索灯光，尚不生成新地形；《光年之外》的太空地图与星球车仍为后续内容。

已接入 PostgreSQL 存档同步：浏览器保存会话令牌，后端存储令牌哈希、昵称、游戏与世界状态，用修订号防止旧存档覆盖。昵称是展示名；游戏 ID 可跨设备恢复，共享排行榜与服务端经济结算尚未实现。当前购买、抽卡和闯关仍由客户端计算，本机探索记录不是多人排行榜。

榜单快照日期 2026-10-08，数据来源与完整名单见 public/catalog 和 docs/plans/2026-10-08-qqmusic-hot-100.md。

生产构建有 Three.js 包体超过 500 kB 的提示；低性能设备帧率和真实移动设备尚未验证。

## 已验证

生产构建及 TypeScript 检查通过；经济系统测试覆盖得分兑换、购买扣款、余额不足、卡包耗尽、五连保证、二十抽保底、每日领取幂等、载具/主题池和存档。

真实浏览器验证：399 米、19 金币、1349 分结算 33 音符；60 音符购买增加库存；拖动包装撕开，五张真实歌曲卡入库；连续翻卡归位；首次猜中获得五连包；道具装备后加速至约 68 km/h；三个世界可选择。

## 2026-10-08 白色界面与开包流程

- 大厅改为白色与珠光渐变，常用入口包括探索、签到、每日猜歌、卡包、仓库与微缩世界。音乐格子跟随指针亮起，支持暂停与减少动态偏好；目前为视觉节奏，不读取音频频谱。
- 立体包装使用环境反射、箔膜材质、封边压纹与局部褶皱，不使用复杂插画。
- 开包依次撕封、卡背露出、包装下落；一次只展示一张卡，点击翻开后选择下一张，最后整包汇总。可以跳过动画直接查看全部。奖励在撕包时入库，跳过与关闭不会重复发奖。
- 五连包只通过赠送/猜歌奖励获得，无法购买。地图包不出售；地图卡混在普通歌曲包中。载具包继续单独出售。旧存档主题包保留兼容。
- 进度保留本机缓存，同时同步 PostgreSQL；断网时显示待同步状态，恢复网络后重试。

## 开包体验适配

卡片统一比例，金卡仅保留金属边框。完整正反两面使用 GSAP 透视翻转、抬升落定与一次扫光；每张卡的动画期间锁定操作。点击卡片或空白处翻开，揭晓后再次点击进入下一张，最后整包汇总。空格、Enter、右方向键也可继续，按钮保持各自操作。汇总卡片交错入场，窄屏自动分行，支持减少动态效果偏好。
