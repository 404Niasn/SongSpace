# 2026-10-08 美术与入口改版

## 对上一版的审查

- 首页直接进入赛道，缺少品牌解释和集合入口，开包、猜歌、收藏的优先级不清楚。
- 卡包只有二维渐变与旋转，没有袋身厚度、热压封边和系列图案。
- 卡片更像专辑列表：缺少编号、统一印刷边框、卡面层次和等级页脚。
- 江南的房屋没有朝向街道，窗户简陋、沿河建筑重复、水面和街道缺少材质细节。
- 镜头偏高偏远，角色与脚踏没有真实联动；金币只是空心圆圈。
- 每日猜歌插画、闯关记录仍偏基础，后续美术质量不应继续按这些占位级别扩展。

## 本轮落实

- 新增品牌大厅：真实海岸场景、明确品牌介绍、开始闯关主入口；开包、猜歌、仓库为主要集合入口，微缩世界与记录次级入口。
- 真正的 Three.js 卡包：鼓起的前后袋面、侧折、金属热压封边；支持指针倾斜和拆封。歌曲/载具/世界三种极简符号，由 Canvas 原生绘制。拒绝使用复杂风景生图。
- 审查参考源码： https://github.com/riba2534/claude-opus-5-5-demo/blob/main/pelican-bike/src/main.js ，重点参考镜头近距离追随、阻尼切换、踩踏与速度联动的思路，未移植其整套游戏。
- 江南：同一建筑模块用于骑行与微缩场景；瓦面曲线、山墙、木格窗、店招、灯笼、花盆，街边房屋正确朝向赛道；河埠台阶、石桥、乌篷船、近对岸、动态水纹与青石材质。建筑同材质几何合并，降低新增细节带来的绘制开销。
- 三种机位按钮：追随 / 侧后方 / 骑手视角，平滑切换；脚、膝盖、踏板按行驶距离联动。
- 实体金币：厚度、边缘凸圈、音符浮雕、金属材质与轻微悬浮。
- 所有歌曲卡统一卡面组件：收藏编号、专辑封面、卡种、歌名歌手、等级和数量；金/彩卡独立底色与印刷效果，未获得灰色。

## 验证与边界

- npm run build：Vue / TypeScript / Vite 构建通过。主脚本仍有大于 500 KB 的体积提示。
- node --experimental-strip-types tests/economy.mjs：经济与收藏回归通过。
- 浏览器实际验证：大厅导航、江南第三人称/侧后方/骑手机位、暂停/继续/结算、实体包装、撕包后翻卡、库存减少、歌曲入库、仓库长歌名无横向溢出。
- 视觉验证期间开了测试库存的一包载具，抽到《孤独患者》，已保存在当前浏览器收藏中。
- 当前仍是风格化程序建模；与参考游戏的完整海洋、布料、电影后期存在差距，不应描述为已全面达到其美术质量。
- 简单昵称、本机进度、三题每日猜歌、主题卡仅夜景这些业务边界不在本轮美术修改中扩大。

## 被否决的生图

- 工具：内置 imagegen。
- 提示方向：深青色与金色的骑行河流、森林、唱片月亮全幅插画。用户明确认为图案过密、意义不清，因此不用于产品、不打包到 public。
- 原始生成文件保留；项目评审档案：docs/design/rejected/pack-night-ride.png。
- 后续图案以单个明确主题、少量颜色、大留白和小尺寸可读为准。
