# 歌境世界工作台

用户要求：像真实产品；允许参考开瓦包的导航、收藏和奖励功能组织，避免照搬微缩城市展示页面。

设计参考：product-workspace-reference.png，通过内置 ImageGen 生成，作为 UI 结构参考，不作为实际 3D 世界的背景图。

## 图像分析与实现约束

- 布局：顶部固定导航，左侧初始世界列表，右侧主要场景工作区。结构平铺，以一条分割线连接侧栏和画布，避免重复嵌套面板。
- 颜色：米白背景约 #f8f5e9、深绿文字约 #234235、珊瑚主按钮约 #e47255；场景仍由三个世界各自的自然色调主导。
- 字体：中文无衬线；地图列表约 14px，操作按钮 13px，工作区标题 22px，不再使用宣传页式巨大标题。
- 空间：导航约 68px；侧栏 250px；场景占余下宽度；侧栏内边距 20px，列表间隔 10px，操作按钮至少 42px 高。
- 主要按钮：「进入漫游」实色珊瑚；「布置世界」浅色描边。微缩/漫游、白昼/黄昏是实际视角与光照切换。
- 使用真实模型渲染得到地图缩略图，而非生成图片替代可交互世界。参考图的写实建筑细节只用于方向，实际世界采用程序化低多边形几何。
- 顶部只提供已可用的「我的世界」「歌曲图鉴」；不复制参考图中的未实现设置/账户入口，不显示虚构音符、抽卡库存或排行榜。
- 歌曲图鉴使用已经下载的 100 首 QQ 音乐歌曲及真实封面，提供搜索、排序、歌曲详情和对应 QQ 音乐链接；不将其标成玩家已经获得的卡片。

## 生成提示摘要

Use case: ui-mockup。独立中文音乐世界游戏工作台；固定导航「我的世界」「歌曲图鉴」；三个初始世界完整歌曲名；左侧地图列表与真实操作；右侧江南水乡 3D 场景；米白、深绿、珊瑚配色；避免宣传页大标题、嵌套卡片、虚构账户余额和不可用导航。

## 闯关版本的重新审视

上一版的核心问题是把游戏设计成了 3D 展示工作台：入口强调看地图、布置和只读图鉴，缺少明确目标、结束条件、奖励和收藏所有权。视觉的克制没有弥补玩法闭环的缺失。

本次采用游戏大厅设计，深色底、浅绿主按钮，顶部明确音符余额与骑行/开包/仓库/世界/记录/猜歌导航。赛道选择放在游戏页，闯关时压缩界面让路给第三人称场景。实时 HUD 给出分数、金币、生命、关卡和目标距离，结算面板明确兑换与到账。

开包页参考开瓦包的实际结构：库存、收藏进度、保底、签到、分系列商店；包装为 CSS 绘制铝箔实体，GSAP 描述撕封、退场、卡片进入与单张翻转。动画只服务于状态变化。仓库的彩色/灰色区分表示实际拥有状态，卡片详情承担装备与歌曲跳转。

当前造型为程序化原创圆润小人，借鉴软萌比例，不是外部游戏模型资产。世界仍为手工程序化几何，微缩部分是矩形底座；无尽骑行独立使用循环路段，避免让微缩边界限制闯关距离。
