# SongSpace 歌境 · 比赛演示视频脚本草案

状态：创意与文字分镜草案；未生成 Seedance 视频，未开始剪辑。真实录屏到齐后再确定镜头入点与出点。

## 方向

- 用途：腾讯音乐高校 AI Hackathon 作品演示。
- 建议规格：横版 16:9、1920×1080、30fps，目标 150 秒，最终不超过表单要求的 3 分钟 / 500MB。
- 主线：歌曲成为地图，抽到的歌曲改变世界。
- 已确认：创意开头与结尾；开头快速讲痛点、闪过专辑封面；中段使用真实录屏配合 HyperFrames；片头片尾计划用 Seedance 2.0。
- 建议待审：150 秒时长、下方旁白与镜头节奏。
- 风格沿用产品封面 v3：冷白、薄荷绿、深绿文字、真实唱片与箔膜材质；克制、精致，避免卡通、金光粒子与复杂幻境。
- 生成镜头只承担概念引入与收尾。实际地图、抽卡、物品和天气效果均用录屏证明。

## 开头 · 0–20 秒

### 0–4 秒：我们收藏了很多歌

画面：专辑封面位于同一固定位置，连续快速切换。约 10–12 张，每张 0.25–0.4 秒；前后保留短停顿。NOT GOOD、夜曲作为视觉记忆点；其余取项目已有真实封面。统一薄白边、轻微纸面阴影，背景一直保持冷白，避免全屏明暗闪烁。

旁白：喜欢的歌，我们听过，也收藏过。

屏幕文字：听过。收藏过。

声音：短促节拍与翻页声音，最后一次切换后留下半拍安静。不把多首歌曲的副歌拼成嘈杂串烧。

实现：HyperFrames 使用真实封面做精确切换，文字由后期排版。

### 4–7 秒：提出一个问题

画面：停止切换，一张《江南》歌曲卡留在画面中央。镜头慢慢贴近卡面，其余封面退到画外。

旁白：但如果，一首歌还能走进去呢？

屏幕文字：如果，一首歌可以走进去？

实现：HyperFrames 完成封面、卡面与 Seedance 首帧的匹配。

### 7–15 秒：歌曲展开为世界

画面：卡片平放在桌面，卡面中的江南建筑逐渐抬升成实体微缩模型。河道向远处延伸，白墙黛瓦、石桥和垂柳出现；微缩世界与黑胶唱片融为一个精致实体模型。镜头低幅向前推进，停在桥和街道方向。只变出一个世界，避免八秒里同时穿越森林、海洋和古镇。

旁白：让歌曲成为地图，让收藏改变世界。

屏幕文字：歌曲成为地图。收藏改变世界。

实现：Seedance 概念镜头。所有中文、Logo 和产品口号用 HyperFrames 后期叠加，不交给生成模型写字。

### 15–20 秒：进入真实产品

画面：在桥 / 街道方向匹配剪切至真实《江南》探索画面，再短切到大厅或探索准备页。品牌文字叠入后撤去，画面正式进入演示。

旁白：这就是 SongSpace 歌境，一款音乐世界探索与卡牌收藏游戏。

屏幕文字：SongSpace 歌境 / 音乐世界探索与卡牌收藏游戏。

实现：真实录屏 + HyperFrames。

## 中段 · 20–136 秒 · 真实录屏 + HyperFrames

每段保留真实操作的起因、结果与反馈，去掉无意义等待、鼠标寻找按钮和重复操作。字幕只解释当前画面，不额外遮盖 UI。

| --- | --- | --- | --- |

| 126–136 秒 | 猜歌 / 签到 / 成就入口、存档已同步状态 | 每日猜歌、签到与成就，带来持续的收获。收藏、装备和世界布置，都能保存下来，继续下一段旅程。 | 日常入口用简短串接；存档状态清晰可见，不展示账号恢复 ID |

## 结尾 · 136–150 秒

### 136–140 秒：从体验回到理念

画面：真实微缩世界录屏，慢慢拉远。最好选择已经有装饰的江南地图，与片头呼应。画面中出现小字“歌曲构成世界，收藏改变世界”。

旁白：让喜欢的音乐，成为属于你的世界。

实现：真实录屏 + HyperFrames；随后匹配切到 Seedance 片尾。

### 140–147 秒：世界归入收藏

画面：白色桌面上的唱片与江南微缩世界。镜头缓慢拉远，建筑与水面轻柔收拢为一张精致歌曲卡，落在唱片旁；卡包与两张卡片停留在桌面。整个过程是物件收拢与镜头退场，不是爆炸、旋涡或魔法消失。最后右侧是唱片与卡包，左侧留出品牌文字空间。

旁白：Build with AI. Build with Music.

实现：Seedance 概念收尾；旁白、文字与 Logo 后期制作。

### 147–150 秒：品牌定格

画面：采用现有封面 v3 的布局或对应干净尾帧。Logo、SongSpace 歌境、产品副标题与口号清晰展示，至少保留 2–3 秒完整可读。

文字：

SongSpace 歌境
音乐世界探索与卡牌收藏游戏
Build with AI. Build with Music.

声音：音乐自然收尾，余音渐弱。

## Seedance 2.0 · 片头提示词

建议生成 8 秒、16:9、无文字、无配乐镜头。参考输入：产品封面 v3 提供材质与色调；江南真实截图提供建筑语言；另准备干净卡片首帧。若界面支持首尾帧，可使用首尾帧约束；具体参数以实际界面可用项为准。

提示词：

高级音乐产品的概念短片，摄影级精致微缩建筑与实物材质，冷白桌面、低饱和薄荷绿、深绿植物、柔和自然光。镜头从一张平放的白边歌曲收藏卡开始，卡面是江南古镇。卡片位置稳定，卡面中的白墙黛瓦建筑缓慢向上展开成真实比例的微缩建筑，青绿河道延伸，细致石桥与垂柳依次出现，形成一个建在黑胶唱片上的小型江南世界。整个展开连续、克制，遵循实体建筑的结构，建筑不融化、不扭曲。镜头缓慢下降并向石桥方向推进，末尾停在可与游戏江南街道镜头衔接的角度。黑胶纹路、瓷白建筑、清澈浅青水面和纸张纹理清晰，画面有足够留白。全程无文字、无 Logo、无字幕，无卡通人物，无发光粒子，无金色装饰，无赛博霓虹，无大幅旋转，不出现复杂奇幻城堡。参考产品封面的高级、安静、干净质感。

建议生成 8 秒、16:9、无文字、无配乐镜头。参考输入：片头成功结果 / 尾帧，产品封面 v3。尽量复用同一唱片和建筑，保持视觉连续。

提示词：

与片头一致的高级音乐产品概念短片，冷白、浅薄荷绿、摄影级微缩江南建筑，柔和自然光。开场是桌面上的黑胶唱片与精致江南微缩世界，镜头缓慢拉远。江南建筑和浅青水面以连续有序的方式逐渐收拢、平整为一张白边歌曲收藏卡，卡片轻轻落定在唱片旁。旁边保留一个银白与薄荷色的实体箔膜卡包，以及另外一张歌曲卡，纸张与包装表面有自然微纹理和准确接触阴影。结尾镜头稳定，实物集中在右半边，左半边保留大面积冷白空白，以便后期添加品牌文字。无任何文字与 Logo，无卡通风格，无金光粒子，无发光旋涡，无爆炸，无高速飞散，无夸张镜头旋转，物体不凭空跳变。最后保持安静定格，延续产品封面 v3 的材质和构图。

## 素材清单与制作分工

| 素材 | 来源 / 制作方式 |
| --- | --- |
| 快闪专辑封面 10–12 张 | 使用项目本地真实封面，包含 NOT GOOD 与夜曲的原版参考；HyperFrames 控制切换节奏 |
| 片头干净首帧与概念尾帧 | 后续用 imagegen 制作；用户认可脚本后再生成 |
| 片尾干净首帧与留白尾帧 | 后续用 imagegen 制作；与片头保持同一材质与场景 |
| Seedance 片头与片尾 | 当前无可调用 Seedance 工具；提示词可在用户的 Seedance 2.0 平台执行，再将结果加入剪辑 |
| 中段实际游戏镜头 | 用户提供原始录屏；逐段记录文件、时间码、事件和选取理由 |
| Logo 与结束品牌页 | 使用本地已有品牌 Logo 和封面 v3；文字后期叠加 |
| 旁白、字幕、配乐、音效 | 旁白草案先确认，音乐只作背景，重点操作保留适量现场声音 |
