# 歌境 SongSpace · 产品总结与功能介绍

> 基于 2026-10-19 当前工作区实现整理。产品展示与截图见 [项目 README](../../README.md)。

## 产品总结

**歌境是一款让歌曲成为可探索场景、可收藏卡牌与可布置景物的 Web 游戏。** 玩家从一首歌出发，在 3D 世界中探索、获得奖励，再将收藏带回自己的世界，形成持续积累的个人音乐空间。

它面向喜欢音乐、轻量闯关、卡牌收藏和场景布置的玩家。浏览器承载完整体验，三张初始地图直接开放，新手补给让玩家注册后即可拆包和探索。

### 可用于演示的产品介绍

歌境，把喜欢的音乐变成可以走进去的世界。在《大海》的海岸公路前进，在《江南》的青石板街穿行，拆开一包歌曲收藏，让它们化作载具、道具、装扮和世界里的风景。每一次探索，都为自己的歌境留下新的收获。

## 核心体验与价值

| 体验价值 | 对应实现 |
| --- | --- |
| 歌曲有可见的空间感 | 五个歌曲主题世界，微缩预览与进入探索的镜头过渡 |
| 收藏可以参与游玩 | 歌曲卡解锁道具、载具、装扮、装饰和地图内容 |
| 每次探索有所积累 | 里程和金币转为积分与音符，用于购买卡包 |
| 世界可以个人化 | 手动布置景物，选择歌曲天气，保存不同地图的布局 |
| 每日有短时目标 | 签到、意象猜歌、成就进度与卡包奖励 |
| 进度可以带走 | 账号 ID 登录、本机缓存、PostgreSQL 存档同步与跨设备恢复 |

核心循环：**选择歌曲世界 → 装备并探索 → 结算音符 → 开包收藏 → 装备、升级或布置 → 再次探索**。签到、猜歌与成就提供额外卡包，补充这条循环。

## 功能介绍

### 音乐世界与探索

- 《挪威的森林》：树林、林间步道与雾化远景。
- 《大海》：海岸公路、动态海浪、棕榈树与灯塔。
- 《江南》：青石板街、石桥、沿河建筑、垂柳与乌篷船。
- 《富士山下》：富士山、湖畔与樱花景致，获得同名彩卡解锁。
- 《光年之外》：月面、陨石坑、基地与星球车景物，获得同名彩卡解锁。

三个世界无需抽卡即可选择。探索准备页提供歌曲封面、实时微缩场景、载具选择、两个道具槽和积分倍率。进入地图后自动前进，玩家通过换道、跳跃和减速收集金币、躲避障碍；每 500 米进入下一关，速度与障碍难度逐渐提高。

镜头支持追随、侧后方和第一人称。地图音乐随探索启动、暂停与结束联动，可关闭或通过链接在 QQ 音乐打开。音乐播放取决于配置音源及浏览器播放许可。

### 卡包与歌曲收藏

当前曲库共 105 首，基础来自 2026-10-08 QQ 音乐热歌榜 100 首快照，并补充玩法需要的歌曲。仓库提供功能分类、歌曲 / 歌手搜索、拥有筛选、详情与外部歌曲链接；卡面展示真实专辑封面及已收录的短摘句。

| 卡片身份 | 功能与示例 |
| --- | --- |
| 装饰卡 | 花园、雪庭、灯笼、唱片亭等景物；《黄昏》《雨爱》提供天气 |
| 道具卡 | 金卡提供歌曲关联能力，如《心墙》的护盾、《反方向的钟》的回溯 |
| 载具卡 | 专属模型或兼容巡航单车，装备后改变载具外观及速度 |
| 地图卡 | 《江南》等对应初始地图；《富士山下》《光年之外》解锁对应新世界 |
| 装扮卡 | 《你的背包》《红色高跟鞋》解锁对应装扮，穿戴进入探索 |

开包流程包含抽屉式唱片盒、拖动或按钮开启、卡背露出、逐张翻卡、整盒汇总。卡牌在开启时入库，跳过和关闭不会再次发奖。歌曲包设有金卡保底，五连包至少包含一张道具金卡。

### 道具与载具

九类道具覆盖护盾、吸币、自动复活、冲刺防撞、回血、冻结动态障碍、延迟双倍金币、回溯和友情加速。出发前最多装备两个道具，每个槽每局使用一次；首张解锁，之后每三个额外副本提升一级，道具最高五级。

| 歌曲 | 专属载具 | 基础速度 |
| --- | --- | --- |
| 《单车》· 陈奕迅 | 后架旧式单车 | 14 m/s |
| 《一路向北》· 周杰伦 | AE86 | 16 m/s |
| 《鲜花》· 回春丹乐队 | 烂摩托 | 15 m/s |

这些载具具有独立模型与乘坐姿态，重复卡最多额外增加 2 m/s。三款载具共用现有三车道探索规则；AE86 尚未加入漂移或独立汽车物理玩法。

### 微缩世界、天气与装扮

玩家可将歌曲意象景物手动摆入矩形微缩世界。库存跨地图共用，撤回返还，每张地图分别保存布局；探索前段会展示已布置景物。

《黄昏》《雨爱》《认真的雪》《阴天》分别解锁夕阳、雨天、雪天与阴天，天气同时作用于微缩场景与探索。装饰值提升积分倍率：每 100 值增加 10%，最高增加 50%。《你的背包》与《红色高跟鞋》提供背包和高跟鞋装扮，各增加 10% 积分；《青花》提供无积分加成的青花信物配饰。支持 3D 预览与穿戴，不消耗歌曲卡。

### 日常、成就与经济

| 入口 | 当前规则 |
| --- | --- |
| 新手补给 | 500 音符、3 个单抽包、1 个三连包、1 个载具包 |
| 探索结算 | 基础每米 1 分、每枚金币 50 分；计入开局锁定的加成后，每 40 分兑换 1 音符，向下取整 |
| 卡包购买 | 单抽 60 音符、三连 150 音符、载具 300 音符；五连仅通过奖励获得，主题包不出售 |
| 每日签到 | 每天单抽包；连续第 5 天额外三连、第 7 天额外五连，每 7 天一轮，断签重置 |
| 每日猜歌 | 3 道意象题按日期轮换，每天 6 次机会；首猜五连、2–3 次三连、4–6 次单抽，奖励只领取一次 |
| 成就 | 12 项，覆盖探索次数、累计里程、最高分、收藏、开包、签到和猜歌 |

### 账号与存档

注册填写 2–16 字昵称，昵称可重名；系统生成 `SS-XXXX-XXXX-XXXX` 账号 ID。使用已有 ID 登录可以跨设备恢复服务端存档，账号弹窗支持查看、复制 ID 和退出。

本机缓存支持连接中断时保留进度，网络恢复后重试同步。服务端保存凭据哈希，以修订号检查防止较旧状态覆盖新进度；冲突会显示提示。退出前会尝试同步，失败时保留当前进度。

存档包含昵称、音符、卡包、歌曲收藏、装备、世界布局与天气、日常及成就进度、最高分和最近十次探索记录。账号 ID 是访问凭据，需像密码一样保存。

## 当前完成度与边界

目前已经形成账号、探索、奖励、收藏、装备、布置与同步的可游玩 Demo 闭环。

| 项目 | 当前状态 |
| --- | --- |
| 三个初始世界、105 首歌曲、开包收藏、日常活动 | 已实现 |
| 九类道具、三款歌曲专属载具、背包与高跟鞋装扮、青花配饰、歌曲天气 | 已实现 |
| 跨设备恢复、本机缓存与云端修订检查 | 已实现 |
| 富士山与太空地图 | 已实现，获得同名彩卡解锁；星球车为场景景物，尚不可装备驾驶 |
| AI 歌曲分析、运行时生成新模型 | 未接入；当前使用内容映射和预制 / 程序化模型 |
| 全部歌曲专属意象 | 尚未完成；部分歌曲仍使用通用模型与遗留分类规则 |
| 服务端经济结算、反作弊、多人排行榜 | 未实现；探索记录为个人记录 |
| 低性能设备与真实移动设备表现 | 待验证；现有窄屏适配不等于真机性能验收 |

产品演示建议按 **大厅 → 开包 → 收藏 → 装备 → 探索 → 结算 → 微缩世界** 展示，让观众直接看到歌曲如何参与玩法和个人世界的积累。
