# 人物装扮框架

- 歌曲装扮独立于骑行技能和世界装饰，纯外观，不改变积分或速度。
- 普通歌曲包可抽到装扮卡；按歌名和歌手共同匹配，拥有一张即解锁。
- 重复卡保留收藏数量，不增加重复衣橱项，不自动替换穿戴。
- 背部、头部、配饰各一个槽位。衣橱支持穿戴、卸下与本机存档恢复。
- 骑行读取已拥有且已装备的装扮，把模型挂载到人物对应部位。

## 首个示例

陈奕迅《你的背包》对应「旅途背包」。卡库中作为 `source_type: prototype` 的补充示例卡；卡面使用自制占位背包插画，歌曲链接指向 QQ 音乐搜索，不虚构歌曲 ID、专辑与时长。待确认正式歌曲资料后替换。

## 后续增加内容

1. `src/game/outfits.ts`：新增装扮 ID、名称、部位、歌名、歌手与预览路径。
2. `src/worlds/outfitModels.ts`：添加对应模型；目前使用占位几何体，可换成正式模型。
3. `public/catalog/qqmusic-hot-100.json`：加入或确认来源歌曲。
4. `public/art/outfits/`：加入预览图。

现有存档使用 `equippedOutfits` 保存各槽位的装扮 ID；模型与预览图替换不影响解锁或穿戴记录。
